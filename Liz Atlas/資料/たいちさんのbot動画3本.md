# たいちさんのbot動画 3本のまとめ

> [!abstract] 先に結論
> 1. 3本とも、Mineflayer を土台にしたbotです。概要欄には Mineflayer 本体へのリンクだけがあり、botのプログラムは公開されていません。使えるのは考え方です。
> 2. **整地と露天掘りは、区画を分けて大勢で掘る形で成功しています。** いっぽう **建築は一部だけで、細かい装飾は人の手で作られました。**
> 3. いちばん難しいのは、止まらずに最後まで動かすことです。露天掘りは11区画を掘って、止まらずに終わったのは1回だけでした。
> 4. 動画のサーバーにはbot向けの優遇（壊したブロックが直接インベントリに入る、空中に置ける）がありました。Liz Atlas では使いません。その分、同じことをするのは難しくなります。

## 1. 60体のボットに整地をさせてみた（2025-05-24）

### 動画で言っていること

- 最大60体のbotで、エンドの島を整地しました。約9時間で約200万ブロックです。
- 作業の範囲を区画に分けました。最終的には、1体に1チャンクを割り当てています。
- 事故がたくさん起きました。
  - 奈落に落ちて死ぬ。
  - 同じマスにbotが集まりすぎて、押しつぶされて死ぬ。
  - 食べ物がなくなって餓死する。
  - ほかのbotの足場を壊してしまう。
- 会話AI（ChatGPT のようなもの）をbotに入れる実験もしました。長く覚えていられないので「おもちゃ」だ、という評価でした。
- この時点では、建築の機能はありません。

### Claude の考え：Liz Atlas にとっての意味

- 区画を分けて1体ずつ割り当てる形は、そのまま使えます。
- 事故の4つは、どれも前もって防げます。立ち位置の予約（同じマスに集まらない）、足場の予約（他人の足場を壊さない）、食料の残りの見張り、落下の対策です。
- 会話AIの評価は、Liz Atlas の方針（定型作業にAIを使わない）と同じ向きです。

## 2. AIボットに建築させてみた（2025-08-01）

### 動画で言っていること

- botが建てたのは建築の一部だけです。約18万ブロックの外装を32個に分け、32体で約5時間かけて建てました。
- 資材の補給は人間が行いました。
- 仮ブロック（足場）の撤去も人間が行いました。
- botは、何もない空中にブロックを置いています。ふつうのクライアントではできない置き方です。
- 1マス下に置きまちがえたことで資材が足りなくなり、止まりました。
- 100万ブロックを超え、300種類を超えるブロックを使う装飾は、botに任せませんでした。範囲が広すぎること、仮ブロックが必要な場所が多いことが理由です。人の手で作られました。
- 開発の時間が足りず、シリーズはここで終わりました。

### Claude の考え：Liz Atlas にとっての意味

- **動画で解決されなかった所が、Liz Atlas の中心になります。** 置いた結果の確認と直し、資材の自動補給、足場の自動撤去の3つです。
- 置きまちがいは、置くたびに確かめ、区切りごとに設計図と照らし合わせれば、広がる前に直せます。
- Liz Atlas は空中に置かない決まりです（[[Liz Atlas 質問と回答]] の Q1）。動画より難しい条件なので、足場の計画が要ります。

## 3. ボットに全自動で露天掘りさせてみた（2026-10-30）

### 動画で言っていること

- 16体で64チャンクを、約8時間で掘りました。
- できるようになったこと：
  - エンダーチェストとシュルカーボックスから、道具と仮ブロックを自分で補給する。
  - いらないアイテムを捨てる。
  - 不死のトーテムが発動したら、自動でサーバーから抜ける。
  - 手の空いたbotが、ほかの区画を手伝う。止まったbotの仕事を肩代わりする。
  - 作業の範囲を、ゲーム内の地図で管理する。
- 11区画（合わせて704チャンク）を掘りました。止まらずに最後まで終わったのは1回だけです。
- 止まった原因：
  - 道具の耐久値の計算まちがい。
  - 水の処理。
  - 自分の足元を壊して落ちる。
  - 特定の座標で移動が引っかかる。
  - 掘る高さの範囲の指定まちがい。
  - 道具が足りなくなる。
  - スポナー。ゾンビのスポナーで、botが4体やられました。
- サーバーには、壊したブロックが直接インベントリに入る、などの改造がありました。botは、見通しのきかない所のブロックも壊せました。
- ツルハシは、1チャンクあたり4.7本使いました。

### Claude の考え：Liz Atlas にとっての意味

- 道具の自己補給、応援、肩代わりは、Liz Atlas でも作ります。
- 止まった原因の一覧は、そのまま試験の項目になります。第3週（水と溶岩）と第5週（無人運転）で、1つずつ確かめます。
- 「止まらない」ことをねらうより、「止まっても自分で再開する」作りにします。進み具合を保存し、どこからでも続きができるようにします。
- Liz Atlas では、落ちたアイテムを歩いて拾います。動画より遅くなります。
- 1体が1チャンクを掘るのに約2時間かかった計算になります（16体で64チャンクを約8時間。私の計算）。動画は採掘速度上昇のビーコンと良い道具を使っています。

## 3本を通して分かること

| 分かったこと | Liz Atlas での扱い |
|---|---|
| 掘る仕事は、区画に分ければ大勢でできる | 露天掘りを最初の目標にする |
| 建てる仕事は、掘る仕事よりずっと難しい | 掘る仕事で土台を作ってから、段階を踏んで建築へ進む |
| 止まらずに動かすのがいちばん難しい | 再開できる作りにし、止まった原因と対処を記録する |
| 資材、確認、足場は人間がやっていた | ここを自分で作る |
| サーバーの優遇に頼っていた | 優遇なしで作る。その分、時間がかかる |

## 分かっていないこと

- botのプログラムの中身。公開されていません。
