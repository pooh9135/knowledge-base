# Liz Atlas 計画まとめ

> [!abstract] 先に結論
> 1. **最初の目標は、16チャンクの露天掘りです。** そのあと整地・伐採・畑・採掘・運搬と仕事を増やし、最後に設計図からの建築へ進みます。
> 2. 期限を延ばしてよいとのことなので、12週の枠を外し、4つの期に組み直しました。建築の入り口（10万ブロック級）までで、約19週の見込みです。
> 3. **バージョンは 26.1.2 のままです。** Minecraft 本体は 26.3 まで出ていますが、Mineflayer が対応しているのは 26.1 系までです。
> 4. **botは、Mineflayer で外からログインする形を続けます。** MODで出すbot（Carpet）は、単純な操作のくり返ししかできません。
> 5. 本番で露天掘りを始めるには、道具の用意が要ります。16チャンクで、ツルハシ約80本ぶんです（私の計算）。ここは、あなたのプレイの進み具合に合わせます。
> 6. **夜は、寝る係（Carpet のbot）が寝て飛ばします。** 2026-11-15 の決定です。ゲームルールとコマンドの決まりの、例外になります。

## この文書について

- 2026-11-14 の回答と、同じ日の調査を反映して書き直しました。2026-11-15 の回答と決定も入れてあります。回答の記録は [[Liz Atlas 質問と回答]] にあります。

## 1. 何を作るか

- Minecraft Java版で、複数のbotが自分で作業を続けるシステムです。フォルダ名は `liz-atlas` です。
- **最初の目標**：たいちさんの動画のように、16チャンクの露天掘りをbotだけで掘り切る。
- **途中の目標**：生活の基盤づくりを手伝う（整地、伐採、畑、採掘、運搬）。
- **最終の目標**：.litematic の設計図をもとに、数百万ブロック級の建築を完成させる。
- **進め方**：いきなり建築はしません。やさしい仕事から順に、1つずつ合格させて進みます。

## 2. 決まっている方針

| 分類 | 方針 |
|---|---|
| AIの使い方 | AIを自分で訓練しない。決まった作業は、AIを使わないプログラムで行う。AIは例外のときだけ呼ぶ「現場監督」にする |
| 学び方 | うまくいった手順をプログラムとして残す。失敗と対処を記録して、次に生かす |
| 設計図 | あなたが用意する（準備中）。Liz Atlas の中では設計をしない |
| サーバー | このPCに新しく立てる Fabric のサーバー。バージョンは 26.1.2 |
| 公平さ | **botを有利にする設定は絶対にしない。** 敵モブあり、落下ダメージあり、ゲームルールの変更なし（例外：寝る人数の割合だけ。2026-11-15 の決定） |
| 置き方 | 空中には置かない。人間にも理論上できる置き方だけ。**最終手段として、設計図の中の建築に限り、簡易設置（空気をクリックする置き方）を使う**（2026-11-15 の決定） |
| コマンド | テスト鯖とクリエ鯖だけで使う。本番のサバイバルでは一切使わない（例外：寝る係を出して動かす Carpet の `/player` だけ。2026-11-15 の決定） |
| 夜 | 1人が寝たら朝になるようにする。Carpet の寝る係が自動で寝る。仕組みはあなたが作る。Liz Atlas のbotは寝ない |
| botの数 | 最終的に 10〜20 体。名前は `LizAtlas_01` 〜 |
| 難易度 | ノーマル。テスト鯖と本番で同じにする（2026-11-15 の決定） |
| 最初に用意する物 | 本番でbotが使う物は、最初はあなたが全部用意する（道具、防具、武器、食料、明かり、ベッド、チェストなど）。数の一覧は第4週に出す |
| 動かす時間 | 1日約 10 時間 |
| 使う場所 | 自分で管理するサーバーだけ |
| 費用 | 監督AIは Claude Code の Max プランでまかなう。利用枠は節約を優先する（調べ物や単純な作業は軽いモデルに任せ、大きな調査の前にはひとこと確認する） |

## 3. 全体の流れ

```mermaid
flowchart LR
    P1["第1期<br>露天掘り<br>第1〜7週"] --> P2["第2期<br>生活の基盤<br>第8〜13週"]
    P2 --> P3["第3期<br>建築<br>第14〜19週"]
    P3 --> P4["第4期<br>大規模建築<br>第20週〜"]
```

- **どの仕事も、まずテスト鯖で合格させます。** 合格した仕事だけを、本番鯖に入れます。
- 露天掘りで作る部品（移動、道具の補充、区画の割り当て、無人運転、再開、通知）は、あとの期でもそのまま使います。
- 各週の終わりに、ゲームの中で確かめる手順を出します。

> [!note] Claude の考え：露天掘りを「建築の仕組みの最初の版」として作る
> - 露天掘りは「この範囲を、すべて空気にする」という設計図を建てる仕事だと考えられます。整地は「この高さより上は空気、下は土」という設計図です。
> - そこで、露天掘りの段階から「設計図と今の世界のちがいを一覧にして、ちがいを1つずつ埋める」作りにします。
> - こうしておくと、整地も建築も、同じ仕組みに設計図を渡すだけで動きます。足場の後片付けも「設計図では空気の場所にあるブロックを壊す」で済みます。
> - Baritone という自動化ソフトが、この作りです。考え方だけを借ります。

> - 経験値瓶は、1本で平均 14 の耐久を直せます（修繕は経験値1で耐久2。瓶1本は経験値 3〜11）。

> - 瓶だけで直すのは高くつきます。経験値トラップでbotが道具を直す形も、候補に入れたいです。第12週の前に、どちらにするかを相談します。

## 6. botのログイン方法（Q2への答え）

### 「MODでbotを出す」について、調べて分かったこと

- **MODでbotを出すことは、できます。** Carpet という MOD の `/player` コマンドです。26.1.2 用もあります。アカウントは要りません。
- ただし、できるのは「使う、攻撃する、跳ぶ、向く、動く、落とす」といった単純な操作と、そのくり返しです。道を探す、持ち物を考える、建てる順番を決める、といった機能はありません。
- 複雑な仕事をさせるには、Carpet 専用の言語（Scarpet）で、すべてを一から書くことになります。
- たいちさんの動画のbotは、Mineflayer です。概要欄に Mineflayer へのリンクがあります。**botがどうやってログインしていたかは、字幕からも検索からも分かりませんでした。**

### Claude の考え

- Liz Atlas は、Mineflayer で外からログインする形を続けるのがよいと考えます。移動、採掘、持ち物を扱う部品がそろっているからです。

### たいち鯖のbotについて（2026-11-15 のあなたの記憶）

- たぶんMODで、コマンドで召喚していた。名前は `taichi_bo1` のような形だった。
- Claude の見立て：コマンドで出す、名前を自由に付けられる、という点は、Carpet の `/player` の特徴と合います。ただし、断定はできません。
- Liz Atlas のbotは、Mineflayer のまま進めます。Carpet のbotは、夜に寝る係としてだけ使います（下の「夜と Carpet」）。

### 夜と Carpet（2026-11-15 の決定）

- 1人が寝たら朝になるように、ゲームルール（`players_sleeping_percentage`）を変えます。
- Carpet のbotを寝る係にして、自動で寝る仕組みを作ります。仕組みは、あなたが作ります。
- 本番鯖にも Carpet を入れることになります。使うのは、寝る係の `/player` だけです。
- Carpet には、アイテムを作り出せる機能（Scarpet）もあります。本番では使いません。使えないようにする設定を、入れるときに公式の資料で確かめます。
- テスト鯖も同じ設定にして、本番と同じ条件で試します。

### ログインの案

| 場面 | 案 | 状態 |
|---|---|---|
| 開発（テスト鯖） | アカウントの確認をオフにする。あわせて、このPCの中からしか入れない設定にする（`online-mode=false` と `server-ip=127.0.0.1`） | **おすすめ。** 第1週はこれで始めます |
| 本番（見学の人が入る） | 下の候補 A（VPN）から、第6週に試して決める | 方向は決定（2026-11-15）。まだ試していない |

本番の候補です。どれも、まだ試していません。見学の人に専用の接続アプリを入れてもらえそう、とのことなので、A から試します。A がうまくいかないときに、C、B の順に試します。

| 候補 | 中身 | 良い所 | 気になる所 |
|---|---|---|---|
| A. 内輪の回線（VPN） | 招待した人だけがつながる回線を使う。サーバーはアカウントの確認をオフにする | 仕組みが簡単 | 見学の人に、回線用のソフトを入れてもらう。入れた人は、どの名前でも入れてしまう |
| B. 中継サーバー（Velocity） | 人間は中継サーバーで正規のログインをする。botは内側から入る | 人間は正規のログインのまま | botを内側から入れる公式の方法が、見つかっていない |
| C. 認証のMOD（EasyAuth） | 正規アカウントの人は自動で通す。botは合言葉で入る | サーバー1つで済む | 26.1.2 用は試作版（ベータ）しかない |

> [!warning] 外からつながる状態で、アカウントの確認をオフにしない
> アカウントの確認をオフにしたサーバーは、だれでも好きな名前で入れます。インターネットにつながない場合だけ使う設定だ、とマイクラの wiki に書かれています。テスト鯖は、このPCの中からしか入れないようにします。

> [!info] 公式の決まり（2026-11-14 に公式ページで確認）
> - サーバーに入れてよいのは、正規の有料版を持っている人だけです（Minecraft Usage Guidelines の「Servers and hosting」）。
> - botや、アカウントの確認をオフにする設定についての記述は、公式ページに見当たりませんでした。
> - 見学の人は、正規版を持っている人だけにします。くわしくは [[マイクラAIボットの研究と資料]] の冒頭の「追記」にあります。

## 7. 難しい点（先に知っておくこと）

### 調査で新しく分かったこと（2026-11-14）

| 分かったこと | 対処 |
|---|---|
| 26.1.2 で、botがサーバーから蹴られるおそれのある不具合がある。直しはまだ正式版に入っていない | 第1週の最初の接続テストで確かめる。だめなら、開発中の版を使う |
| 移動用の部品（mineflayer-pathfinder）は、正式版が 2023 年から止まっている。水、階段、鍾乳石で引っかかる報告がある | 第1週に、正式版と開発中の版を比べて決める |
| 便利な追加部品（自動で食べる、道具を選ぶ、など）が 26.1 で動くかは、確かめられなかった | 動かないものは、自分で作る |

### 露天掘り

- **道具の用意が一番の手間です。** 1チャンクで、耐久力IIIのダイヤのツルハシが約5本要ります（私の計算。動画の実績は 4.7 本）。
- **速さは道具で大きく変わります。** 採掘速度上昇IIのビーコンがあると、石は一瞬で壊れます。
- **落ちたアイテムは、歩いて拾います。** 動画のサーバーは、壊したブロックが直接インベントリに入る改造をしていました。
- **止まらずに動かすのは難しいです。** 動画でも、11 区画のうち止まらずに終わったのは1回だけです。「止まっても自分で再開する」作りにします。

### 建築

- 張り出しと高い所の足場は、動画の作者が断念した所です。
- 額縁、絵画、防具立て、看板の文字、旗の模様、水や溶岩は、botでは置けないかもしれません。「人間があとで置く一覧」を出します。
- AIに建築をさせた研究では、成功率は一番良いもので4割ほどでした。Liz Atlas は、AIに置かせず、決まったプログラムで置きます。
- .litematic を読む部品は、公開されているものが3つあります。第14週に試して選びます。合わなければ自分で作ります。
- 建築の進め方は、Baritone という自動化ソフトの作りが参考になります。設計図と今の状態のちがいを一覧で持ち、置く前に「この向きで置くと何になるか」を試算する作りです。プログラムは写さず、考え方だけを借ります。

### 簡易設置について、調べて分かったこと

- Litematica の簡易設置は、人間が使うクライアント用MODの機能です。Mineflayer のbotからは、そのままでは使えません。
- 向きのあるブロックを正しく置くには、サーバー側にもMOD（Carpet Extra か Servux）が要ります。バニラのままで正しく置けるのは、ハーフブロックだけです。
- 配布ページには「いつも、置きたい場所の空気ブロックをクリックする」と書かれています。空中に置かない決まり（Q1）と合いません。

> [!important] 決定（2026-11-15）：簡易設置は、最終手段として使う
> あなたの回答：「簡易設置を奥手にします。空中に置けてしまいますが、設計図内だけですし、建設以外はできないの最終手段で使おうと思います。」
>
> 置き方は、次の順に試します。
> 1. **通常の置き方**。すでにあるブロックの面に置きます。視線の向きと、クリックする面と位置の組み合わせを試算して、ねらった向きになる置き方を選びます（Litematica Printer というMODの考え方を借ります）。
> 2. **簡易設置**。1 で置けない所に限り、設計図の中の位置へ、空気をクリックして置きます。建築のときだけ使います。
>
> まだ決まっていないこと：向きのあるブロックを簡易設置で正しく置くには、サーバー側のMOD（Carpet Extra か Servux）が要ります。これを入れるかどうかは、第16週に 1 の成績を見てから相談します。
